# Xtravon Studio

Digital fashion studio — from idea to finished garment in one connected journey:

**Inspiration → Design → Customisation → Measurements → Consultation → Approval → Production → Fitting → Quality Check → Delivery**

> Create It. Consult. Watch It Come to Life.

Full spec: see [PRD.md](./PRD.md).

## MVP (from PRD)

- Customer registration, Design Studio, templates + inspiration + image upload
- Measurement profiles, consultant chat + booking, design review + `APPROVE & START PRODUCTION`
- Orders, production tracking + updates, change requests, fitting workflow
- Payment tracking, delivery/collection, notifications, customer dashboard
- Admin portal + feature flags

## Roles

Customer, Fashion Consultant, Production Staff, Quality Control, Administrator, Organisation Manager.

## Stack (planned)

Next.js App Router + TypeScript + Tailwind + Supabase (auth, DB, storage).
